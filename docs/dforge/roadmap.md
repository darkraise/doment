# doment — roadmap

**Product:** a self-hosted, low-latency remote desktop for the owner's own machines: desktop work, coding with managed remote terminals, gaming, unattended support and remote power-on, built on darkraise-framework with NativeAOT
**Spec:** docs/dforge/specs/2026-11-24-doment-design.md
**Non-goals:** enterprise fleet features, circumventing protected content or anti-cheat, phones and tablets as hosts, renting or provisioning cloud machines
